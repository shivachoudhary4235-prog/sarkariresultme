# OpenSEO Strategy for Sarkari Result Portal

This skill outlines workflows for using the OpenSEO Model Context Protocol (MCP) server to drive top Google Search and Google Maps rankings for the Sarkari Result portal.

## OpenSEO MCP Capabilities
- **Keyword Research**: Analyze search volume, keyword difficulty, CPC, and intent for high-intent keywords (e.g., `Sarkari Result 2026`, `UP Police Constable Admit Card`, `RRB NTPC Result`, `BPSC TRE 4.0`).
- **SERP Inspection**: Track live Google Search organic rankings and competitive footprints.
- **Local Maps Ranking**: Audit local pack listings, category taxonomies, and Google Business Profiles to achieve #1 map rankings.
- **Google Search Console**: Query clicks, impressions, CTR, and indexing status.

## Target Keyword Taxonomy
1. **Primary Head Terms**:
   - `Sarkari Result`, `Sarkari Result 2026`, `Sarkari Exam`, `Sarkari Naukri`
2. **Category Terms**:
   - `Latest Jobs`, `Admit Card`, `Exam Results`, `Answer Key`, `Syllabus`, `Teaching Jobs`
3. **High-Velocity Examination Terms**:
   - `UPTET 2026`, `RRB NTPC 2026`, `SSC CGL 2026`, `BPSC TRE 4.0`, `CTET 2026`
4. **Geo & Local Maps Ranking Terms**:
   - `Sarkari Result office`, `Sarkari Result center`, `Job notification center Delhi / UP / Bihar`
